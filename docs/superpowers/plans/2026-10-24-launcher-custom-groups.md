# 启动器自定义分组与隐藏选择确认

按 superpowers:executing-plans 在当前工作区实施，保留此前全部未提交改动。

方案：恢复添加、启动、设置三个底部图标。分组或搜索隐藏了本次选择中的账号时，启动前显示一次完整账号及分组名单，确认后才发送原 LaunchInstance 命令；全部可见时直接发送。确认期间若后台移除或禁用账号，名单随之更新，不补入未展示的新选择。

数据：account_groups 继续保存昵称到稳定 ID 的映射；account_group_definitions 保存稳定 ID 到分组名。缺失定义时提供旧有 favorites/warehouse/other，读取不改写旧配置。新组使用 UUID；重命名只改名称。全部仅是视图；favorites 始终为默认、不可删除，允许改名但保留默认身份。删除分组将所有归属转入默认，并在一次配置保存中清理定义及当前视图。

界面：紧凑下拉依次提供全部、实际分组、分隔、新建、管理；不增加常驻按钮。管理对话框支持重命名和删除，非空删除先明确确认。移组、添加和编辑使用同一动态分组列表。添加/编辑的命令追加可选分组 ID，只有原账号保存成功后记录归属；旧命令格式继续兼容，不改登录/启动扩展。
